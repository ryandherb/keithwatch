# keithwatch
The better ani-cli-client

### What is this?
Glad you asked, random citizen! This is a GUI to interact with the awesome terminal tool, ani-cli. The terminal tool allows you to watch anime in your... terminal (duh). This GUI allows you to watch it here, in a nice container.

## Features
* Watch anime in the keithwatch app
* Search anime from the app, and see paginated results
* Favorite anime, put anime on your watchlist, get notified when new anime release
* See your history of watched anime
* Download anime, and manage downloaded anime
* EVEN MORE!
